# Virtual Mouse using AI

This project uses **hand gestures** and **voice recognition** to control the mouse.  
Built with Python, OpenCV, MediaPipe, and Speech Recognition.

## Features
- Move mouse with your index finger
- Left click (index + middle fingers)
- Right click (middle + ring fingers)
- Scroll using up/down movement
- Say "close mouse" to exit

## Libraries Used
- `opencv-python`
- `mediapipe`
- `pyautogui`
- `numpy`
- `speechrecognition`
- `pyaudio` *(for microphone input)*
- `threading`
